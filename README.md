## Bye GitHub, Hello Codeberg!

I am in the process of migrating my personal projects over to [Codeberg](https://codeberg.org/ngie) for personal/ethical reasons.

I will continue to have a presence on GitHub for the time being, but it will not be the primary source of truth for [F]OSS development I do.

The reasons for my migration to Codeberg align with other projects, such as [Gentoo Linux](https://www.gentoo.org/news/2026/02/16/codeberg.html) and [Zig](https://ziglang.org/news/migrating-from-github-to-codeberg/). [Janik von Rotz's blog post](https://janikvonrotz.ch/2025/08/20/migrate-from-github-to-codeberg/) is an excellent read that encapsulates my thought on the current state of GitHub.

## Notes on Contributions/Communication

* All commits I make to any repositories (GitHub or otherwise) after September 2026 should be GPG-signed.
    * If they are not, question the submission.
    * I do this to help provide authenticity for any contributions made using my account.
* All LLM-assisted commits will be annotated using `Assisted-by:`.
* Any official communications I make to third-parties should be signed using my [current PGP key](https://keys.openpgp.org/search?q=yaneurabeya%40gmail.com).
    * Some emails may be sent unsigned due to the fact that many mail clients lack PGP integration, but in general, important communications will be PGP signed.

## Solicitation Not Welcome

If I'm ever interested about something, I will contact the relevant parties.

Any solicitation emails received after 10/2026 will be binned to `/dev/null`.

### Work Offers

Do not email me about work opportunities without providing a job requisite/application I can research before submitting my resume. 

### "AI"/LLM-related Topics

I am not looking for Agentic skills, coding agents, etc. I am actually very opposed to large LLM providers and am opposed to using ethically questionable models (OSS and non-OSS) for a variety of personal reasons.

## How-tos

### Migrate from GitHub to Codeberg

I made a simple python project for migrating GitHub repos to Codeberg called [Sidney](https://codeberg.org/ngie/sid). This project has not been posted to PyPI (I don't think I'll go through the effort of doing that, but plans can change..).

All development is taking place on Codeberg of course.
